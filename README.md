# BLVietsub Cloudstream Extension Repository

Kho lưu trữ tiện ích mở rộng xem phim Đam Mỹ **BLVietsub** cho ứng dụng **Cloudstream** trên Android TV Box, Smart TV và điện thoại Android.

## 📺 Link cài đặt vào Cloudstream
Copy link sau và dán vào mục **Cài đặt -> Tiện ích mở rộng -> Thêm kho lưu trữ**:
`https://raw.githubusercontent.com/your-github-username/blvietsub-cloudstream/builds/plugins.json`

## ✨ Tính năng
- 8 Danh mục: Mới Cập Nhật, Phim Bộ, Phim Lẻ, Hoàn Tất, Thái Lan, Trung Quốc, Hàn Quốc, Nhật Bản.
- Tìm kiếm phim chính xác với tên gốc hoặc tên tiếng Việt.
- Bóc tách đầy đủ các tập phim và máy chủ.
- Luồng phát 1080p HLS trực tiếp từ SSPlay và Dailymotion.
